💡 Cara Cepat Mendapatkan Kunci Supabase (100% Gratis):
1. Buka supabase.com > Daftar akun gratis > Buat project baru (misal: izdiihar-cell).
2. Buka menu SQL Editor di Supabase > Paste isi file supabase_schema.sql > Klik Run.
3. Buka menu Project Settings > API di Supabase > Salin Project URL dan anon / public key ke bawah ini.
Kunci aman level browser (anon/public key).
